# 🧪 Лаборатория и Сниппеты (R&D)

Здесь хранятся полезные математические алгоритмы, старые прототипы и черновики, которые мы пока не тащим в основной продакшен-код `core`.

### Список сниппетов:

*   **`calibrator_v1.rs`** — Чистый математический движок автокалибровки локальной сетки в глобальные координаты (WGS84) методом итеративного перебора (брутфорса) трехградусных зон Гаусса-Крюгера (проекция `tmerc` на эллипсоиде Красовского). 
    *   *Сфера применения:* Маркшейдерия, геодезическая привязка карьеров/шахт в Сибири (коридор 87° - 91° долготы).
    *   *Зависимости:* Требует системную библиотеку `libproj` и крейт `proj`.
